# R1 FrontScreen

海康威视 R1 / R1X NAS 前置触摸屏的硬件管理工具：Material You 三页信息面板（环境/详情/系统）、Web 控制面板、智能风扇调速、天气展示。

> **能装的机器只有一个系列**：海康威视 **R1 / R1X**（Intel N100）。它内置一块 376×960 的触摸屏，
> 程序用 KMS/DRM（`/dev/dri/card*`）直接画在屏上，再读背光 sysfs 与风扇 hwmon 做控制。
> 普通 PC、群晖、威联通装了也点不亮 —— 它们没有这块屏，也没有对应的背光与风扇节点。
> 还需要能 SSH 进 fnOS（或 Debian 系）并拿到 `sudo`。
>
> 满足这三条就往下看 [部署方式](#部署方式)：一条命令装完，不用装 Go，也不用编译。

> 本项目基于 [lemon6515/r1-toolbox-go](https://github.com/lemon6515/r1-toolbox-go) 增强 fork 而来，遵循上游 **GPL-3.0 + Commons Clause** 许可证，感谢上游作者的开源工作。

## 本 fork 的主要改进

| 方向 | 内容 |
|---|---|
| **性能** | CPU 占用从约 89% 优化到 **单核约 2%**（60 秒窗口实测在 1.6%~2.3% 之间波动，长期基线 2.1%；跳帧渲染 + 局部重绘 + 圆角遮罩缓存 + 亚像素插值 + 采样减频） |
| **安全** | Web 面板令牌鉴权（首次启动自动生成）；令牌明文只在**点按系统页控制卡里的「面板令牌」行**时显示 10 秒（物理接触即授权，路过的人看不到）、亮度/风扇曲线等接口输入校验、修复磁盘监控数据竞争（`-race` 验证）。**注意面板是明文 HTTP，仅限内网使用**，详见 [安全说明](#安全说明) |
| **体验** | 负载阈值色（读数与进度条同一套：**<50% 常态 · ≥50% 沙金 · ≥80% 珊瑚**；进度条常态为薄荷绿，不再有「黄字配绿条」）、天气图标静态化（相位冻结）、屏幕夜间自动调暗（18:00–06:00 背光降至 `night_brightness`）、配置文件保存保留注释、崩溃自愈（systemd 加固） |
| **可读性** | 指标数字常态色降到 `#D4D4D4`（纯白在 376×960 小屏上会「发光」，降一档后不再抢标题与点缀色的注意力）；时钟、卡片标题、主机名仍为纯白，保留信息层次顶端 |
| **可靠性** | systemd 看门狗（`Type=notify` + `WatchdogSec=30`，主循环卡死 30 秒内自动重启，不再「进程活着但画面定格」）、smartctl/lsblk 硬超时（D 状态进程不会卡住渲染）、采样移到后台协程 + 不可变快照（`-race` 实测归零）、GitHub Actions 五道门（fmt/vet/test/test -race/build） |
| **代码** | 渲染器模块化拆分（canvas / design / textrender / theme / widgets；设计常量与阈值取色集中在 `design.go`，改配色只动一处）、删除无人消费的死代码 |

## 硬件与系统要求

- 海康威视 **R1** 或 **R1X** NAS（程序经 SDL2 输出到前置屏幕，走 KMS/DRM 的 `/dev/dri/card*`；另需背光 sysfs 与风扇 hwmon。**无法在普通电脑上运行**）
- 飞牛 fnOS 或 Debian/Ubuntu 系发行版
- 编译需要 Go 1.19+；Docker 构建方式无需在本机装 Go

### 字体

两族分开渲染、各自探测，互不影响：

| 用途 | 字体 | 来源 |
|---|---|---|
| 数字 / 拉丁 | **IBM Plex Sans**（Thin / Light / Bold） | **嵌在二进制里**，首次启动解到 `/tmp/r1-toolbox-fonts/`，用户不用装 |
| 中文 | Noto Sans CJK → 文泉驿微米黑 → 文泉驿正黑 → Droid | 探测系统字体，从前到后取第一个能打开的 |

- **为什么拉丁要嵌字体**：数字必须等宽。Cantarell 的数字是比例宽度（100px 下 `1`=42px、`8`=58px），时钟从 `15:31` 换成 `08:05` 会宽出 41px；试过 Inter 更糟（44px）。IBM Plex Sans 十个数码完全等宽，且本就是给仪器面板设计的。字体按 OFL 1.1 分发（见 `internal/ui/assets/fonts/OFL.txt`）。
- **为什么中文不嵌**：思源黑体单个字重就 10MB，塞进二进制不划算。想用思源的话执行 `sudo apt install fonts-noto-cjk`（约 100MB）即可自动生效，没装则退回 wqy —— 两种都不影响功能。

## 设计规范（改界面时照这个来）

界面的一致性靠规则约束，不靠手感。八张卡片共用一套规格：

| 项 | 规则 | 代码位置 |
|---|---|---|
| **卡片标题** | **18px、卡色实色、距卡顶 +13、左内边距 22、字距 0** | `DCardTitle` |
| **卡名** | 2–4 字对象名，不带修饰词（「CPU」「内存」「磁盘」「温度」「设备」「网络 IP」「Docker」「控制」） | — |
| **右上角信息** | 16px、右对齐、与标题**同墨迹中心**、用语义色（结论用 mint/coral/sand） | `DMetaR` |
| **文字色阶** | 主值 `colWhite` / 次值 `colSub` / 标签 `colDim` / 分隔符 `colTab`，四级不混用 | — |
| **间距（TPart.Gap）** | **3** = 标签或单位紧跟值 · **7** = 并列项之间 · **8** = 「·」两侧 · **10** = 斜杠两侧留白 | — |
| **卡片配色** | 同页四张卡色相不重复；环境页 slate/rose/sand → sage/mint，详情 slate/rose/mint/sand，系统 slate/mint/rose/sage | — |

> 间距只有四个档位。2026-11-01 之前这里散落着 2/3/4/5/6/7/8/9/10 九个值，
> 同样的「数字 + 单位」在不同卡片里疏密不一 —— 看起来没毛病，但整屏就是不齐。

## 部署方式

> **三条硬前提**：海康 R1 / R1X · fnOS 或 Debian 系 · 能 SSH 进系统并拿到 `sudo`。
> 不满足的话，装完只会得到一个跑起来但点不亮屏幕的进程 —— 它要的是这台机器内置的那块屏，
> 不是任何显示器。

### 方式 A：一条命令（推荐）

```bash
git clone https://github.com/mingyangbest/r1-frontscreen.git
cd r1-frontscreen
sudo ./install.sh
```

不想 clone 整个仓库的话，只取脚本也一样（默认路线不需要仓库里其它文件）：

```bash
curl -fsSL https://raw.githubusercontent.com/mingyangbest/r1-frontscreen/master/install.sh -o install.sh
sudo bash install.sh
```

脚本取 **Release 里的预编译包**，不装 Go、不编译，全程不提问：

1. 先检查机型、`/dev/fb0`、`/dev/dri/card*`，不对就停下来说清楚原因
2. 只装运行时依赖（`libsdl2-2.0-0`、`libsdl2-ttf-2.0-0`、中文字体、`smartmontools`、`lm-sensors`、`i2c-tools`）
3. 下载 `r1-toolbox-linux-amd64` 并校验架构（Release 带 `.sha256` 时一并核对），旧二进制自动备份
4. 已有配置 `/etc/r1-toolbox/config.yaml` **先备份、不覆盖**（备份在 `/var/backups/r1-toolbox/`），只补缺失的

装完会直接告诉你三件事：屏幕是否点亮、面板地址 `http://<设备IP>:8080`、令牌在屏幕哪一页看。

常用参数：

| 参数 | 用途 |
|---|---|
| `--port 9000` | 面板端口（仅首次生成配置时生效） |
| `--version v0.9.6` | 装指定版本，默认最新 |
| `--binary ./r1-toolbox-linux-amd64` | 离线安装：用本地包，不联网 |
| `--from-source` | 从源码编译（改代码 / ARM 主板） |
| `--fix-grub` | 移除 GRUB 里的关屏参数（会改引导配置） |
| `--force` | 跳过硬件检查（无屏环境） |

> **下载卡住**：GitHub 在国内时通时不通。在能上网的机器上取
> `https://github.com/mingyangbest/r1-frontscreen/releases/latest/download/r1-toolbox-linux-amd64`，
> `scp` 到 NAS，然后 `sudo ./install.sh --binary ./r1-toolbox-linux-amd64`。

<details>
<summary>从旧版升级 / 手动管理服务</summary>

- 升级直接重跑 `sudo ./install.sh`：二进制换新、配置不动、服务自动重启。
- 旧版 `install.sh` 把配置写在 `/etc/r1-control/config.yaml`，和程序读的路径不是一个地方；
  新脚本会把它迁移到 `/etc/r1-toolbox/config.yaml`，你设过的端口与风扇曲线不会丢。
- 旧单元是 `Type=simple` 的话，新单元会覆盖它；如果另外加过 drop-in，记得删掉重复的
  `Type=` / `WatchdogSec=`：

```bash
sudo mkdir -p /etc/systemd/system/r1-toolbox.service.d
printf '[Service]\nType=notify\nWatchdogSec=30\n' | \
  sudo tee /etc/systemd/system/r1-toolbox.service.d/override.conf
sudo systemctl daemon-reload && sudo systemctl restart r1-toolbox
```

- 服务名、二进制名、配置路径沿用上游的 `r1-toolbox`（`systemd` 单元 / `/usr/local/bin/r1-toolbox` / `/etc/r1-toolbox/`），从上游或旧版升级无需迁移。

```bash
sudo systemctl status r1-toolbox   # 查看状态
sudo journalctl -u r1-toolbox -f   # 看日志
/usr/local/bin/r1-toolbox --version  # 查当前版本（v0.9.7+；更早的版本会启动第二个实例）
```

</details>

### 方式 B：从源码编译（改代码 / ARM 主板）

```bash
sudo ./install.sh --from-source
```

会装 Go 与 SDL2 开发库再 `make build`。R1 上首次编译约 1–3 分钟；ARM 主板只能走这条。
没有 Go 环境也可以用仓库里的 Docker 编译：

```bash
docker compose run --rm build      # 产物落在 ./build/r1-toolbox
```

### 方式 C：Docker 容器运行（⚠️ 实验性）

屏幕渲染需要特权设备访问，容器方式仅作尝试，**不保证在所有固件上可用**：

```bash
docker compose up -d screen   # privileged + /dev/fb0 + host 网络
```

遇到问题请回退方式 A。日常使用**推荐方式 A**。

### 方式 D：fpk 应用包（飞牛应用中心形态）

那才是完全不懂命令行的人能「点一下装好」的形态，但要走飞牛官方 `fnpack` 打包并逐固件实测。
**本仓库暂未附带打包配置**，现在请走方式 A。

## Web 控制面板

启动后浏览器访问 `http://<设备IP>:8080`。面板用 `X-Token` 头鉴权（首次访问会提示输入一次，之后存在浏览器本地）：

- **怎么拿令牌**：在设备屏幕上滑到「系统」页，**点一下「控制」卡里的「面板令牌」一行**，屏上显示明文 10 秒（原底部的令牌/数据药丸已删除，令牌并入控制卡）
- 也可以直接读文件：`sudo grep token /etc/r1-toolbox/config.yaml`
- 令牌只接受 `X-Token` 头，不走 URL 参数（避免被访问日志抄走）；连续 8 次错误锁定该 IP 5 分钟

能做什么：

| 分组 | 内容 |
|---|---|
| 屏幕 | 亮度、自动关屏时长、开 / 关屏（关屏需点两次确认） |
| 显示 | 主题（墨 / 素 / 沙 / 青）、12–24 小时制、天气显示或隐藏、刷新节奏（2 / 3 / 5 秒）——**改完立刻生效** |
| 风扇 | CPU / 机箱风扇的模式与温控曲线、PWM 通道与温度源映射（映射需重启服务生效） |
| 灯效 | RGB 模式与颜色（R1 前屏未见系统级灯效通路，可能无可见效果） |
| 硬件 | hwmon 扫描，列出本机风扇与温度传感器，换机器时用它确定通道 |

## 安全说明

**面板是明文 HTTP，没有 TLS，请只在内网使用。** 令牌在网络上明文传输，同一局域网内的嗅探者可以截获；拿到令牌就能控制这块屏幕（改亮度、关屏、调风扇）。

- **不要直接做端口映射到公网。** 如果确实要外网访问，请在前面加一层带 HTTPS 的反向代理（Caddy / Nginx / Traefik 均可），由反代终结 TLS，并且至少再加一道认证：

  ```
  # Caddy 示例（自动申请证书）
  screen.example.com {
      reverse_proxy 192.168.1.10:8080
      basicauth { admin <bcrypt-hash> }
  }
  ```

- **令牌目前没有轮换接口。** 泄露后的处理办法是手改配置文件并重启服务：

  ```bash
  sudo sed -i 's/^\(\s*token:\).*/\1 换成新的8位令牌/' /etc/r1-toolbox/config.yaml
  sudo systemctl restart r1-toolbox
  ```

- 面板不提供「重启服务 / 执行命令 / 上传文件」这类入口，**不要**为了图方便给它加一个。

## 配置

配置文件：`/etc/r1-toolbox/config.yaml`（程序每 5 秒热重载，改完即生效）。字段说明见 [`config.example.yaml`](config.example.yaml)。

天气数据来自[心知天气](https://www.seniverse.com/)免费接口，API Key 继承自上游项目（已随上游公开）；如失效可自行注册并替换 `internal/netinfo/netinfo.go` 中的 `senKey`。

## 已知限制

- 侧边 RGB 灯条：上游代码保留了 RGB 模块，但在 R1 前屏硬件上**未发现系统级软件控制通路**（实测内核 LED / I2C / ACPI 均无接口），灯效可能由屏体 MCU 硬件自带
- **设备卡的盘位数来自机型映射表**（当前仅 `HS-AFS-R1` → 4 盘位），不是硬件读数——Linux 没有暴露「盘位数」的通用接口，DMI 的 chassis 只报机箱类型。未映射的机型不显示该项。其余字段（机型名、CPU、内存类型与容量、fnOS 版本）**全部为系统实读**，读不到就整项省略，不填占位符
- 本程序为非官方项目，与海康威视、飞牛官方均无关联；刷写/安装产生的风险自负

## 项目结构

```
cmd/main.go            程序入口
cmd/preview/           设计稿离屏渲染工具（把候选版面画成 PNG，不参与运行、不占屏幕）
internal/ui/           屏幕渲染：canvas / design（设计常量与阈值取色）/ textrender / theme / widgets / pages
internal/monitor/      CPU / 内存 / 网络 2 秒采样，磁盘 SMART / Docker 60 秒采样（后台协程 + 不可变快照）
internal/hardware/     背光、风扇曲线、触摸屏、hwmon 发现
internal/web/          Web 控制面板（gin + 内嵌前端，令牌鉴权）
internal/netinfo/      网络信息与天气（30 分钟刷新）
internal/config/       配置热重载（yaml.Node 键级合并，保留注释与键序）
web-ui/                Web 面板前端源码（Vue 3 + Vite）
```
