## 一句话简介

海康 R1/R1X 前置触摸屏管理：三页信息面板、Web 控制、CPU 与硬盘风扇自动调速、背光与夜间调暗、异常告警与 Bark 推送。

## 应用描述（应用中心「详细介绍」栏可直接用）

为海康威视 R1/R1X 存储服务器的 376×960 前置触摸屏提供完整的管理界面：

- **三页信息面板**：环境页（CPU/内存/网络/Docker 概览）、详情页（磁盘与卷状态）、系统页（设备信息、公网 IP、风扇转速、亮度控制）
- **风扇自动调速**：CPU 与机箱风扇分别按温度曲线自动调速，机箱风扇跟踪真实盘体温度（多盘取最高），与屏幕显示的盘温同源
- **背光管理**：亮度滑条、夜间（18:00–06:00）自动调暗、超时息屏
- **Web 控制面板**：浏览器访问 8080 端口（令牌鉴权），改配置即时生效无需重启
- **异常告警**：CPU/硬盘温度、磁盘容量、SMART 异常、容器异常、断网检测，支持防抖与静默期，可推送 Bark
- **主题与排版**：4 套主题（墨/素/沙/青），数字使用等宽字体，滑动 60fps

安装时自动探测背光节点与 it87 风扇芯片，校验 DSI 前置屏（376×960）后才放行——不满足机型的设备会明确提示并中止安装，不会装出黑屏。

## 权限说明（非特权运行）

应用主体以 `r1-frontscreen` 用户运行，不申请 root 常驻。它需要三类系统资源：

1. 前置屏渲染读取 `/dev/dri/card1`（root:video 660）→ 安装时把用户加入 `video` 组
2. 容器状态读取 `/var/run/docker.sock`（root:docker 660）→ 加入 `docker` 组
3. 背光与风扇 PWM 写 `/sys/class/backlight/*` 和 `/sys/class/hwmon/*/pwm*`（root:root）→ 安装时写入 udev 规则 `99-r1-frontscreen.rules`，对 `video` 组开放 0660 写权限，卸载时删除

生命周期脚本（`install_callback` / `uninstall_callback`）以 root 执行，只做三件事：创建用户、加入组、安装或移除 udev 规则。安装结束后没有常驻 root 进程。

Web 面板只监听一个端口，令牌鉴权，无令牌不启动（fail-closed）。配置落在 `@appconf`，数据（历史库、告警记录）落在 `@appdata`。卸载会停止进程、删除应用目录与 udev 规则，**配置文件保留**，重装后沿用，这是 fnOS 的惯例；要彻底清干净，卸载后手动删掉 `@appconf/r1-frontscreen`。

## 数据与网络行为

- 本地存储：24 小时指标历史（SQLite）、告警记录（JSONL）、网络日计数——全部在应用私有目录
- 出网请求仅两类：天气图标查询（公开天气接口，只读，可关）、Bark 推送（地址由用户自填，默认关闭，接口永不回显密钥）
- 无遥测、无账号体系、无云端依赖

## 已知限制

- 仅海康 R1/R1X 有效（安装时三重硬件校验，其他机型装不上）
- 桌面入口固定跳转 8080 端口；修改 `config.yaml` 的 `web.port` 后入口指向旧地址，面板仍可通过新端口手动访问（fnOS 1.2.0903 不解析 ui/config 端口占位符，实测）

## 测试情况

**非特权形态**（fnOS 1.2.0903 / R1 实机，2026-11-04，v1.0.1）：

- 应用中心安装：通过，应用以 `r1-frontscreen` 用户运行（uid 966，组 AppUsers / video / docker）
- 开机自启：重启后未手动启动，进程自行起来。内核启动到进程 87 秒，到面板可用 94 秒，屏幕正常出画面
- 崩溃自愈：`kill -9` 后 5.2 秒拉起
- 卡死自愈：`kill -STOP` 后 64 秒被判定并重启，旧进程被替换
- 桌面入口：点图标跳转到面板，通过
- 令牌鉴权：无令牌 401，正确令牌 200
- 卸载清理：应用目录、udev 规则、进程清除；配置文件按 fnOS 惯例保留
- 升级保留配置：卸载重装后配置沿用
- 非目标机型拒装：root 形态 2026-11-03 用伪造 sysfs 验过三例；非特权形态本轮未重测，安装脚本的校验逻辑与当时相同

**root 形态**（2026-11-03）另有十项记录。那一版的分发形态与当前包不同，不作为本包的测试依据，只作历史参考。
